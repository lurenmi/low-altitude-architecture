一、核心结论

1. 侦测市场正在从“设备采购”升级为“治理闭环”

公开采购样本显示，客户仍会采购单套探测识别、反制或警用无人机装备，但项目名称和交付内容越来越常见“侦测及反制装备”“无人机反制系统”“智能管控平台”等组合式表达。真正可复制的产品不应停在硬件参数，而要把设备告警转为工单、处置、证据和复盘。

2. 国内重点竞品已进入“城市级低空安全”叙事

杰能科世、雷擎科技等厂商公开页面已不只强调反制设备，而是强调城市级监管、重大活动保障、重点区域防护、多源感知和低空安全综合解决方案。这意味着浙大启真若只做设备集成，会被拖入参数竞争；若做运营闭环，则有机会形成差异化。

3. 国际成熟产品的共同方向是开放、融合、自动化

D-Fend、SRC、DroneShield 等强调 RF、雷达、光电、电子战、C2 平台和开放 API 的组合。可学习的不是某一种反制方式，而是“多传感器融合 + 指挥控制 + 快速部署 + 持续软件更新”的工程化方法。

4. 最稳的产品定位：平台主导、设备开放、运营兜底

建议浙大启真定位为“低空侦测与安全运营产品体系”，前端设备采用多厂商可替换生态，核心沉淀在规则引擎、目标融合、告警可信度、联动处置、审计留痕、运营报表和试点方法论。

二、事实依据与市场约束

维度 公开事实 对侦测产品的含义
监管制度 《无人驾驶航空器飞行管理暂行条例》自 2024-01-01 施行；CCAR-92 明确民用无人驾驶航空器运行安全管理框架；GB 46750-2025、GB 46761-2025 于 2026-05-01 实施。 合规无人机的实名、识别、运行数据会越来越标准化，但存量、改装、关闭识别、弱信号、复杂电磁环境仍需要多源侦测。
飞行规模 民航局 2025 统计公报披露，注册无人机 328.7 万架，全年飞行 4530.29 万小时，低空飞行服务站 46 个、覆盖 23 个省级地区。 低空安全不再是临时安保问题，而是高频运行秩序问题；侦测系统必须支持常态值守、审计和运维。
产业政策 工信部等四部门《通用航空装备创新应用实施方案（2024-2030年）》提出到 2030 年通用航空装备全面融入生产生活各领域。 低空基础设施、场景应用和安全保障将同步建设；侦测产品应跟低空平台、园区、起降点、应急体系联动。
采购锚点 公开中标样本从 28.8 万元级反制系统、36 万元级探测识别设备，到 225 万元、244.88 万元级警用无人机及反制装备组合不等；广州公安 2025 年无人机反制设备招标预算 360 万元。 市场存在“单点设备、组合装备、系统工程、运营服务”多层价格带。产品包必须分层报价，避免只有一个大而全方案。

真实性口径：上表金额为公开采购公告样本，不代表全国均价；厂商参数来自官网公开页面，不等同于实测验收结果；本报告的“强弱判断”是基于公开材料的产品化推断。

三、产品体系拆解：客户真正买的不是“看见一架无人机”

感知层

RF 侦测、Remote ID/运行识别接收、雷达、光电/红外、声学、5G-A 通感、便携/车载/固定站。关键指标是覆盖、误报漏报、弱信号、复杂环境适应。

融合研判层

多源目标关联、轨迹重建、白名单/黑名单、禁限飞区、行为模式、风险分级、告警可信度。关键是把多设备告警变成一个业务目标。

联动处置层

告警确认、工单派发、短信/电话/政务消息、现场回传、反制授权、处置闭环。关键是角色、权限、留痕和响应时效。

运营审计层

设备在线率、链路质量、告警趋势、处置时长、误报分析、月报周报、复盘档案、SLA。关键是把项目交付变成持续服务。

平台接口层

对接低空飞行服务平台、公安/应急/园区平台、视频平台、GIS/CIM、机库、第三方设备。关键是开放 API 和统一数据模型。

场景产品层

园区版、活动版、重点目标版、城市治理版、应急机动版、机场净空协同版。关键是用不同价格带覆盖不同预算和验收逻辑。

七、浙大启真差异化路线

产品主张

不卖“设备清单”，卖“低空安全运营闭环”。硬件负责看见目标，平台负责判断风险，流程负责联动处置，运营负责持续变好。

多源感知融合研判工单闭环审计留痕运营报表

首期最小可行产品

优先做 3 个可演示闭环：夜间黑飞、活动保障、敏感区越界。每个闭环都要有固定输入、固定角色、固定输出和固定验收指标。

首期不要追求全城覆盖，先把“发现-研判-派单-处置-归档-复盘”跑稳定。

设备生态策略

建立设备适配白名单：RF、RID、雷达、光电、车载、便携、反制设备均以标准数据模型接入。对外强调开放兼容，对内沉淀适配器和质量评分。

竞争护城河

真正难复制的不是界面，而是场景规则、告警可信度、处置流程、部门协同、审计材料、运维机制和可复用项目包。

建议立项口径：浙大启真低空侦测与安全运营产品体系 = 前端侦测站网 + 多源融合研判平台 + 联动处置工作流 + 运营审计服务 + 场景产品包。
